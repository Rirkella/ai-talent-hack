# Avito AI Reviewer

**Предварительный помощник для ревьюеров образовательных программ Авито**

---

## О проекте

**Avito AI Reviewer** — это веб-сервис, который помогает ревьюерам и методистам проверять домашние работы по продуктовому менеджменту. AI-ассистент готовит предварительную оценку по критериям, показывает основания из работы и формирует черновик обратной связи. Финальное решение всегда остаётся за человеком.

Продукт создан для сокращения рутинной работы и ускорения проверки без потери качества.

---

## Основные возможности MVP

- **Каталог из 5 заданий** направления `product` с собственной рубрикой для каждого.
- **Загрузка файлов** в формате DOCX и поддержка дополнительных материалов (анкеты, таблицы XLSX).
- **Автоматическая проверка** по каждому критерию с указанием балла, объяснения и ссылки на место в работе.
- **Генерация черновика** обратной связи для студента.
- **Сигнал использования AI** — отдельный индикатор, который не влияет на оценку.
- **Экран ревьюера** для подтверждения, исправления или отклонения предложений AI.
- **Распределение работ** между ревьюерами и контроль статусов.
- **Сравнение AI и человека** на слабой, средней и хорошей работах.
- **Демо-доступ** по временной HTTPS-ссылке для полноценного тестирования сценария.

---

## Как это работает

1. В систему загружается работа студента (DOCX) и при необходимости дополнительные файлы.
2. Система проверяет файл на наличие персональных данных.
3. Определяется задание и подгружается соответствующая рубрика.
4. Из документа извлекаются текст, таблицы, заголовки и формулы.
5. AI по каждому критерию предлагает:
   - балл;
   - обоснование;
   - цитату из работы с указанием места.
6. Формируется черновик комментария студенту.
7. Ревьюер проверяет предложения, вносит правки и подтверждает итог.
8. Результат и статус сохраняются. Методист видит общую картину загрузки и сроков.

## Технические детали

- **Язык интерфейса:** русский  
- **Форматы файлов:** DOCX, XLSX  
- **AI-модуль:** внешняя LLM с возможностью замены на локальную модель  
- **Безопасность:** маскировка ФИО, email, телефонов и других чувствительных данных перед отправкой во внешние сервисы  
- **Хранение:** результаты проверки и история изменений сохраняются  
- **Деплой:** демо-версия развёрнута по временной HTTPS-ссылке (не production)

## Как оценивается качество

- Два эксперта независимо оценивают слабую, среднюю и хорошую работы по официальной рубрике.
- AI получает только условие и работу — без меток качества.
- Сравниваются:
  - баллы по каждому критерию;
  - пропущенные ошибки и ложные замечания;
  - точность оснований;
  - полезность фидбэка;
  - количество правок от ревьюера;
  - время и стоимость обработки.

---

## Правила оценки

`Предложение AI = сумма баллов по официальным критериям`

`Итог = сумма баллов, подтверждённых или изменённых ревьюером`

**Сигнал использования AI** отображается отдельно и **не** влияет на оценку автоматически. Он лишь привлекает внимание ревьюера к возможным признакам.
